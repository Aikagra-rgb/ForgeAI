# Public Data Sources — Demo 2: Maritime Ports & Liner Shipping (LINERLIB)

Public benchmark dataset from **LINERLIB** (Liner Shipping Network Design benchmark repository):
1. **`ports.csv`** — Global port directory with UN/LOCODE, coordinates, draft limits, and fixed/variable port call costs.  
   URL: https://raw.githubusercontent.com/blof/LINERLIB/master/data/ports.csv
2. **`fleet_data.csv`** — Container vessel classes, TEU capacities, speed ranges, and daily charter/fuel parameters.  
   URL: https://raw.githubusercontent.com/blof/LINERLIB/master/data/fleet_data.csv
3. **`linerlib_readme.md`** — LINERLIB dataset documentation and column definitions.  
   URL: https://raw.githubusercontent.com/blof/LINERLIB/master/README.md
